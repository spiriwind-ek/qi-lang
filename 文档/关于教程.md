## 入门

### 运行方式

```bash
# 运行文件
python3 -m qi run hello.qi
# 或中文子命令
python3 -m qi 运行 hello.qi

# 格式化代码
python3 -m qi fmt -i hello.qi

# 交互式 Shell
python3 -m qi shell
qi> 输出"你好，世界！"。
你好，世界！
qi> 退出
```

### 第一个程序

```
注：这是我的第一个奇语言程序
输出"你好，世界！"。
```

保存为 `hello.qi`，运行：

```bash
python3 -m qi run hello.qi
```

### 编译缓存

第一次运行后，目录里会出现 `_qicache_/` 文件夹，里面是编译产物（`.简令` 文件）。下次运行若源码没改过，直接加载缓存，跳过编译。

## 变量

### 声明

```
令整数年龄为18。
令文本名字为"张三"。
令小数身高为1.75。
令布尔已婚为假。
```

`令` 声明一个变量，格式：`令类型名字为值。`

### 类型推导

```
令X为10。      注：自动推断为整数
令Y为"hello"。 注：自动推断为文本
```

### 修改

```
令整数X为10。
设X为20。
设X为X加1。
```

## 运算

### 算术

```
令整数X为10。
令整数Y为3。
输出X加Y。    注：13
输出X减Y。    注：7
输出X乘Y。    注：30
输出X除Y。    注：3
```

### 比较与逻辑

```
输出X等于10。      注：真
输出X大于5。       注：真
输出真且假。       注：假
输出真或假。       注：真
输出非真。          注：假
```

### 中文数字

源码里可以直接用中文数字：

```
令整数甲为二十。
输出甲。  注：20
```

支持：一、十、十五、二十五、一百、一百二十三……

## 控制结构

`：`/`。` 括号式配对。块内多条语句用 `；` 连接。

### 条件

```
若X大于0则：输出"正数"。否则：输出"非正数"。
```

多语句块：

```
若X大于0则：令整数Y为1；设Y为Y加1。否则：输出"负数"。
```

多分支：

```
若X大于0则：输出"正"。再若X等于0则：输出"零"。否则：输出"负"。
```

### 条件循环

```
令整数X为0。
当X小于10时：设X为X加1。
输出X。
```

### 计数循环

```
重复3次：输出"好"。  注：输出好、好、好
```

### 遍历循环

```
令整数列水果为["苹果"、"香蕉"、"橙子"]。
对水果的每个名称：输出名称。
```

## 函数

### 定义与调用

```
令整数求和为（整数甲、整数乙）：返回甲加乙。
输出求和（3、5）。  注：8
```

函数体支持所有语句类型——if、while、repeat、foreach、input 都可以写在函数里：

```
令空问候为（整数n）：
    重复n次：输出"你好"。
问候（3）。
```

### 递归

```
注：计算 5 的阶乘
令整数阶乘为（整数n）：
    若n等于1则：返回1。
    返回n乘阶乘（n减1）。
输出阶乘（5）。  注：120
```

## 数据结构

### 列表

```
令整数列库存为[10、20、30]。
输出库存[1]。      注：10（索引从 1 开始）
输出库存的长度。    注：3
```

列表操作：

```
令整数列数据为[3、1、2]。
调列表库的排序（数据）。
输出数据[1]。  注：1
```

### 结构体

```
令结构学生含：文本姓名、整数年龄。
令学生小明为学生含（"小明"、18）。
输出小明的姓名。    注：小明
设小明的年龄为19。
```

### 成员方法调用

```
输出文本库的长度（"hello"）。  注：5
输出文本库的替换（"a-b-c"、"-"、"/"）。  注：a/b/c
```

## 输入输出

```
读（"请输入你的名字："）。
输出"你好，"加_input。
```

`读` 读取用户输入，结果自动存入 `_input` 变量。

## 模块系统

```
包括"./数学工具.qi"。
令整数结果为加法（3、5）。
输出结果。
```

`包括` 在编译时加载并编译指定文件的内容。不支持绝对路径。

## 代码格式化

```
python3 -m qi fmt -i hello.qi
```

`-i` 直接修改文件。不加 `-i` 则在终端显示格式化结果。

格式化工具会自动转换中文数字、统一标点。

## 最佳实践

### 命名

变量名、函数名用中文，清晰表意：

```
令整数用户年龄为18。
令整数计算平方为（整数X）：返回X乘X。
```

### 注释

```
注：这个函数计算两个数的和
令整数求和为（整数甲、整数乙）：返回甲加乙。
```

## 完整示例：斐波那契数列

```
注：计算斐波那契数列前 10 项
令整数斐为（整数n）：
    若n小于等于1则：返回n。
    返回斐（n减1）加斐（n减2）。
令整数I为0。
当I小于10时：输出斐（I）；设I为I加1。
```
