# 奇语言 语法规范

## 设计哲学

用中文写代码，像写文章一样自然。

## 基本约定

1. 语句以 `。` 结尾
2. 代码块用 `：` 开始，**缩进**结束（类似 Python）
3. 块内多条语句换行写，自动缩进对齐
4. 同一行内多条语句用 `；` 连接
5. 参数用 `、` 分隔
6. 变量声明必须指定类型，声明后类型不可变更（支持类型推导）
7. 成员访问用 `的`

## 标点符号

| 符号 | 用途 |
|------|------|
| `。` | 语句结束 |
| `；` | 行内连接多条语句 |
| `：` | 代码块开始 |
| `、` | 分隔参数 |
| `（）` | 参数列表 / 函数调用 / 输入提示 |
| `"` | 文本字面量 |
| `[` `]` | 列表字面量 / 列表索引 |

## 类型系统

### 基础类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `整数` | 整数 | `令整数X为42。` |
| `小数` | 浮点数 | `令小数X为3.14。` |
| `文本` | 字符串 | `令文本S为"你好"。` |
| `布尔` | 布尔值 | `令布尔B为真。` |
| `空` | 函数无返回值 | `令空F为（）：输出1。` |
| `无` | 空值 | `输出无。` |

### 复合类型

| 类型 | 声明方式 | 说明 |
|------|----------|------|
| `整数列` | `令整数列X为[1、2、3]。` | 整数列表 |
| `小数列` | `令小数列X为[1.1、2.2]。` | 浮点列表 |
| `文本列` | `令文本列X为["a"、"b"]。` | 字符串列表 |
| `结构` | `令结构学生含：文本姓名。` | 结构体 |

## 控制结构

缩进分块——`：` 后换行 + 缩进，缩进归零自动结束块。

### 条件

```qi
若X大于0则：
    输出"正数"。
否则：
    输出"非正数"。
```

多分支（`再若`）：

```qi
若X大于0则：
    输出"正数"。
再若X等于0则：
    输出"零"。
否则：
    输出"负数"。
```

行内单语句（兼容旧风格）：

```qi
若X大于0则：输出"正数"。否则：输出"非正数"。
```

### 条件循环

```qi
当X小于10时：
    设X为X加1。
```

行内：

```qi
当X小于3时：设X为X加1；输出X。
```

### 计数循环

```qi
重复5次：
    输出"Hello"。
```

### 遍历循环

```qi
令整数列水果为["苹果"、"香蕉"、"橙子"]。
对水果每项名称于：
    输出名称。
```

## 函数

### 定义

缩进模式（推荐）：

```qi
令整数求和为（整数甲、整数乙）：
    返回甲加乙。
```

行内单语句（兼容旧风格）：

```qi
令整数求和为（整数甲、整数乙）：返回甲加乙。
```

函数体内支持所有语句类型：

```qi
令空问候为（整数n）：
    重复n次：
        输出"你好"。
```

### 递归

```qi
令整数阶乘为（整数n）：
    若n等于1则：
        返回1。
    否则：
        返回n乘阶乘（n减1）。
```

### 调用

```
令整数结果为求和（3、5）。
输出结果。
```

## 列表

```
令整数列库存为[10、20、30]。
输出库存[1]。        注：10（索引从 1 开始）
输出库存的长度。      注：3
设库存[2]为99。    注：修改
```

## 结构体

```
令结构学生含：文本姓名、整数年龄。
令学生小明为学生含（"小明"、18）。
输出小明的姓名。    注：小明
设小明的年龄为19。
```

## 成员方法调用

```
调列表库的排序（数据）。
输出文本库的长度（"hello"）。    注：5
输出文本库的替换（"a-b-c"、"-"、"/"）。  注：a/b/c
```

`调` 用于将方法调用作为独立语句执行（不返回值）。

## 输入输出

```
读（"请输入你的名字："）。
输出"你好，"加_input。
```

`读` 读取用户输入，结果存入 `_input` 变量。

## 模块导入

```
包括"./数学工具.qi"。
```

`包括` 在编译时加载并编译指定文件。不支持绝对路径。

## 注释

```
注：这是注释，不会被执行。
```

## 上下文关键字

奇语言的关键字是**上下文相关**的。同一词在不同位置可以是关键字或变量名：

```
令整数长度为10。        注：长度 是变量名
输出列表的长度。             注：长度 是关键字（在 的 后面）
文本库                        注：模块名（不会被拆成 文本+库）
文本库的长度("hello")        注：标准库方法调用
```

## 标准库

通过 `模块.方法(参数)` 调用：

| 调用 | 结果 |
|------|------|
| `文本库的长度("hello")` | 5 |
| `基础库的数值化("123")` | 123 |
| `列表库的排序([3、1、2])` | [1、2、3] |
| `列表库的拥有([1、2、3]、2)` | 真 |

详见[关于接口](关于接口.md)。

## 代码格式化

```
python3 -m qi fmt -i 文件.qi
```

格式化工具自动转换中文数字、统一标点。

## 编译缓存

运行后自动生成 `_qicache_/` 目录，存放编译后的 `.简令`（`.qic`）文件。下次运行若源码没改过，直接加载缓存。
